# GAME100 自作デモ音源

このディレクトリの49個のWAV（BGM6曲・SE43個）は `scripts/generate-audio.py` が数学的な波形合成だけで生成したGAME100用の仮音源です。外部のサンプル・録音・既存曲・ゲーム音を使用していません。外部素材のライセンス表記は不要です。プロジェクト内で編集・再生成・差し替えできます。

- 再生成：`python3 scripts/generate-audio.py`（Python標準ライブラリのみ）
- PCM 16bit / 22050Hz / mono、合計約7MB。

BGMは `scripts/compose-bgm.py` に6曲を独立した譜面・編成として記述。同じアルペジオのテンポ違いだった初版から作り直しました。

| ファイル / 曲名 | テンポ・調性 | 編成と展開 |
| --- | --- | --- |
| `common/bgm.wav` / COIN-OP PARADE | 124BPM・ハ長調 | ゲームセンターをイメージしたチップ音の主旋律、FMブラスの裏拍和音、シンコペーションのベース、スネア。8小節の呼びかけと応答、後半にきらめく応答音 |
| `game001/bgm.wav` / GLASS GRID | 96BPM・イ短調 | ガラス風FMの疎な旋律、長いパッド、9thを含む和音。スネアのバックビートを使わない浮遊感 |
| `game002/bgm.wav` / VOLTAGE RUN | 136BPM・ヘ短調 | 短いFMベースリフ、四つ打ち、クラップ、オフビートのハイハット。5小節目から高音リフが入る |
| `game003/bgm.wav` / AFTERGLOW TABLE | 82BPM・ニ長調 | 柔らかいエレピ、拡張和音、ウォーキング風ベース、スイングしたブラシ。会話向けに疎な旋律と小さい音量 |

BGMは各16小節（約28〜47秒）。音の余韻を先頭へ折り返して周期的に合成。SEは立ち上がり・減衰を付け、全音源のピークを制限。
- `manifest.json` にパス・長さを記録。`src/audio/sounds.ts` の静的requireと長さ定義も同じスクリプトで生成します。

これは製品用に選曲・マスタリング済みの音源ではありません。端末ごとの音量、長時間聴いた際の疲れ、ネイティブプレーヤーのループ境界は実機で調整してください。素材を差し替える場合は利用権を確認し、再生時間の定義も更新してください。

NEON PATHの専用曲「QUIET CIRCUIT」は88 BPM・16小節。E minorの保留感のある和音、短い2音の電子信号、半拍感の低いパルスと意図的な休符を組み合わせた戦略向けの曲です。移動・ジャンプ・壁設置・ゴールにも個別SEを追加。既存ゲームの音源は変更していません。

NEON SLING専用「CROSSFIRE」は142 BPM・16小節。B minorの掛け合うスタブ、ブレイクビート、後半の上昇フレーズを用いた対戦用の新曲です。選択・発射・衝突・ゲート通過・勝利・カウントダウンのSEも自作。既存曲・SEのデータは変更していません。
