# ASOBIT 公開用文案

## App Store Connect

表示名：ASOBIT - みんなのゲームセンター

サブタイトル：100日でゲーム30本に挑戦

説明：

スマホの中に、ゲームセンターを。

ASOBITは、ひとりでも、友達とも、家族とも遊べるミニゲームを集めたゲームアプリです。

そして現在、ゲーム制作未経験の会社員が「100日でゲーム30個」に挑戦中。ゲームはアップデートで1本ずつ増えていきます。

現在遊べるゲームは5本。ブロックを積んで消すBLOCK DROP、ボールで崩すBLOCK BREAK、大小の駒をかぶせるNEON STACK、壁と移動で競うNEON PATH、引いて離して撃ち合うNEON SLING。2人対戦はスマートフォン1台で遊べます。

迷ったら「何やる？」でランダムに選択。お気に入りの登録や、メインカラー・BGM・効果音の設定もできます。

100日間の企画は2026年10月1日から2027年1月8日まで。まずは30本。その先も、ASOBITの遊びは増えていきます。

## 次回スクリーンショットのコピー

1. ASOBIT／スマホの中に、ゲームセンターを。
2. 100日で、ゲーム30本。／ゲーム制作未経験の会社員が本気で挑戦中。
3. 今日は、何して遊ぶ？／パズルも、アクションも、頭脳戦も。
4. ひとりで、気づけば夢中。
5. スマホ1台で、すぐ対戦。
6. 2人同時に、本気で勝負。
7. まずは30本。／ゲームは、まだまだ増える。

2枚目には「挑戦中」と現在の収録数を明示し、30本収録済みと誤認させない。旧GAME100のRAWは現行ブランド素材として使用しない。
