# GAME100 共通オーディオ

## 構成

Expo SDK 57の `expo-audio ~57.0.5` を使用。`expo-av` は使用しません。音源は外部取得していない自作仮音源です。[音源の由来と再生成](../assets/audio/README.md)を参照。

- `src/audio/AudioProvider.tsx`：保存設定の読み込み・更新、AppState、HOMEのBGM、初期化失敗の案内。
- `src/audio/audio-manager.ts`：BGM1台、場面別のSEプール、フェード、再生頻度・同時数・非同期キャンセル。
- `src/audio/native.ts`：Expoとの接続。ネイティブモジュールを読めないクライアントでもゲーム画面は起動可能。
- `src/audio/types.ts`：設定、場面ごとのSE一覧、コンボ段階。
- `src/audio/sounds.ts`：音源ID・静的アセット参照・ミリ秒単位の長さ。
- `src/games/00N/audio.ts`：ゲームイベントから音源IDへの変換。ゲームエンジンにExpo依存を持ち込まない。

## 設定と操作

「設定」タブ、各ゲームの「？ 遊び方」内、BLOCK DROP / BLOCK BREAKの一時停止から設定可能。NEON STACKの対戦画面は引き続きスクロールしません。

BGM・効果音はそれぞれオン/オフ。保存キーは `@game1000/settings/audio/v1`。初期値はオン、BGM音量0.32・SE音量0.7。将来のスライダー向けに両音量を0〜1で保持し、不正値を補正します。設定の読み込みが終わるまで音を出さず、素早い連続操作の保存も順番に処理します。

端末の消音に従い、他アプリとmixWithOthersで共存。録音権限・バックグラウンド再生・ロック画面コントロールは不要なため無効。Androidではこの設定で音声フォーカスを要求しません。そのため音声フォーカスだけに依存せず、AppStateのinactive/backgroundとAndroidのblurで止めます。電話や通知・Bluetooth切断などの実機検証は必要です。

## 再生制御

- HOME・ゲーム一覧・ゲーム開始前（BLOCK BREAKはステージ選択）は共通のHOME BGM。スタート操作後は各ゲーム専用BGMへ切り替える。開始前からゲーム用SEを準備し、BGMの変更だけではSEプールを作り直さない。ステージ選択へ戻るとHOME BGMに戻す。
- BGMは常に1プレーヤー。画面変更時は120msでフェードアウトして解放し、新曲を120msでフェードイン。2曲を重ねません。フィーバーではBGMを変更せず開始・終了SEで知らせます。
- PauseはBGMの音量を0にして停止し、Resumeは同じプレーヤーをフェードイン。バックグラウンド中はSEもキャンセル。OS側から再生を再開されても、ゲームがPause中のBGMと停止済みSEは音量0のままです。
- 戻ってきてもPause中のゲームのBGMは再開しません。HOMEと時間制限のないNEON STACKは状態に応じて再開。
- SEはシーン入場時に生成。破壊音のみ各2台、他は1台。最大22台のSEプレーヤー＋BGM1台で、ゲーム数に比例して増えません。シーンを離れると旧SEをすべて解放。
- 同時SEは最大4音。破壊音は段階をまたいで45ms間隔、移動110ms、UI70ms。重要なジングルは通常SEを止めて優先。
- 毎フレームや衝突ごとのプレーヤー生成はありません。ロード未完了音は鳴らさず、120msを超える遅いseekは破棄して後の操作に音が遅れて乗らないようにします。
- seek中の無効化・画面切り替え・バックグラウンド・解放で世代番号を更新し、古いPromiseから再生しません。
- 音声エラーをゲーム進行に伝播させません。音の操作はアニメーション・Hapticsと同じイベント処理で発火します。完全な実機同期遅延は別途確認してください。

## イベント対応

| 場面 | 効果音 |
| --- | --- |
| HOME / 一覧 / ROAD TO 100 | ゲームカード、人数、何やる？等のTap、下部タブ。スクロール・描画時は無音 |
| BLOCK DROP | 開始、成功した移動・回転、ハードドロップ、通常固定、1〜4ライン別、レベルアップ、ゲーム終了または新記録 |
| BLOCK BREAK | 発射開始、コンボ1〜4/5〜9/10〜19/20以上の破壊音、フィーバー開始・終了、共通取得＋各3アイテム、ミス、ステージクリア、全10ステージクリア、ゲーム終了 |
| NEON STACK | 開始・再戦、小中大の配置、相手へのかぶせ、勝利、引き分け、不正配置、1手戻す |
| NEON PATH | 開始・再戦、移動、飛び越え、壁選択・回転・確定、違反警告、ゴール、1手戻す |

ソフトドロップには連続SEなし。ハードドロップと固定が同時に出たときは着地音のみ。勝利・全クリア等は通常音より優先。新記録は終了の下降音の代わりに明るいジングル。レベルアップは文字でも表示し、既存の視覚・振動による結果表示を維持します。

## 検証

134テストで既存ゲームのルールを含めて確認。音声の13テストはモックプレーヤーを使用し、1万件の破壊イベントで最大4音・生成数不変、非同期seekのキャンセル、背景復帰とPause、設定の破損、音源の実在・振幅・ループ境界、音の段階、シーン切り替えと解放を確認。

iOS / Androidのバンドルを生成済み。iPhone 17 Pro Max / Expo Goでホームと設定・音声初期化を確認。依存追加直後のExpoAssetエラーはExpo Goの完全再起動で解消しました。再発時はExpo Goを更新・再起動し、開発ビルドならネイティブ依存追加後の再ビルドが必要です。

実機の音を聴いた確認、Android実機、ネイティブ再生負荷中のFPS計測、着信・Bluetooth・他アプリの音楽との組み合わせ、保存設定の実機再起動確認は未実施。自動テストの負荷結果は実機FPSの保証ではありません。
