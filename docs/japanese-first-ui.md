# GAME100 共通UI方針：日本語ファースト

#004以降を含む全ゲームに適用する。ブランドとネオン表現は保ち、操作・ルール・状態は日本語だけで理解できるようにする。小学校高学年でも分かる自然な言葉を使い、英語はタイトルや演出の補助に限る。

## 共通実装

- `src/data/ui-text.ts`：操作の共通文言 `UI_TEXT` と、各ゲームの3〜5項目の説明 `GAME_HELP`。
- `src/components/game/common.tsx`：`GameButton`、`HelpButton`、`GameInstructions`、`HowToPlayModal`、`confirmGameAction`。
- 開始画面に短い遊び方を表示する。読了や永続フラグで開始を強制的に止めない。ヘッダーの「？ 遊び方」でいつでも見直せる。
- プレイ中の遊び方表示は先に一時停止する。閉じても自動再開せず、「ゲームに戻る」で再開する。
- やり直しと途中終了は日本語で結果を説明して確認する。結果画面からの再挑戦には追加確認を要求しない。
- 表示文言は描画側で扱い、ゲームの計算・衝突・保存とは分離する。#002の通知は `presentation.ts` で日本語に変換する。

## 表示・アクセシビリティ

- 本文は基本14〜16pt、操作ボタンは16pt・最低44×44pt（共通ボタン48pt）。日本語の本文に装飾的な等幅書体を強制しない。
- ボタン・説明は文字サイズに合わせて伸び、長いメニューと遊び方はスクロールできる。固定盤面の短いHUDや発射案内だけ拡大率・行数を制限する。
- 小型端末でも読める日本語を主表示にする。色以外にも選択チェック、ステージの選択マーク、鍵、残り数、アイテム文字を使う。
- カードには番号・名前・日本語説明・人数・ジャンル・遊べるかを表示。準備中のゲームは「準備中」と明示する。
- 日付は日本語、得点は桁区切り、人数は「1人で遊ぶ」等。HOMEの「何やる？」を維持する。
- 対戦中の画面はスクロールさせず、HUD・操作欄を確保した残りの領域に盤面を収める。詳しい説明や名前入力は別の画面・モーダルで扱う。
- 端末の安全領域を尊重し、盤面を小さい機種の固定幅にそろえない。#002は左右合計5％の余白。フェーズ・コンボ・アイテムの有無で盤面の大きさを変えない。

## 新規ゲームを加えるとき

1. 共通文言・部品を利用し、`GAME_HELP` に3〜5項目の遊び方を登録する。
2. 初回の開始前説明、いつでも開ける遊び方、一時停止、日本語の再挑戦・終了導線を設ける。
3. 2人以上のゲームは番号・記号でもプレイヤーを区別する。
4. 小画面・大画面・文字拡大・安全領域・44ptタップ領域を確認する。
5. lint・型チェック・既存ゲームの回帰テストを実施する。

現時点の実装対象は#001〜#004。NEON STACK / NEON PATHは時間制限のない交互対戦のため一時停止ボタンは設けず、遊び方・終了確認・やり直しを用意する。新規ゲームにもこの方針を適用する。

音声は[共通Audio基盤](audio.md)を使用し、BGM・効果音を個別に切り替えられるようにする。重要な結果や状態は音だけで伝えず、文字・視覚演出を必ず併用する。

メインカラーは[設定タブの共通テーマ](settings.md)で管理する。新しいUIはuseColors／useThemedStylesで選択色に追従し、プレイヤーやゲーム要素の識別色は維持する。
