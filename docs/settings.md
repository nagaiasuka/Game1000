# 設定タブとテーマ

下部ナビゲーションの5番目に「設定」（`/settings`）を追加。サウンド設定の通常の入口をHOMEからここへ移し、ゲーム内の遊び方・一時停止からのサウンド操作も維持します。

メインカラーはネオンシアン・ミント・ラベンダー・アンバー・ローズの5色。既存の暗い背景は維持し、ロゴ・共通ボタン・枠・見出し・選択中のタブなどの主アクセントを即時に変更します。選択肢は色名・チェック・アクセシビリティのchecked状態でも識別できます。ゲームの駒・ブロックの識別色は固定です。

`src/theme/ThemeProvider.tsx` はReact Contextで変更を通知します。画面やゲームをkeyで再マウントせず、`useColors()`と`useThemedStyles()`で色・既存StyleSheetのコピーを更新。StyleSheetの変換はメモ化し、共有スタイルを変更しません。新しい画面もこのフックを利用し、選択色をモジュール初期化時の変数へ取り込まないでください。

保存キーは `@game1000/settings/theme/v1`、値は `{ "mainColor": "cyan" }` 等。サウンドの保存キーとは分離。読み込み中は選択操作を無効化し、保存は順番に処理。不正値はシアンへ戻し、読み書き失敗は日本語で表示します。

テーマ設定の3テストは、不正・既存データの復旧、共有スタイル不変・アルファ付きアクセント・副色の保持、全5色と背景／ボタン文字のコントラスト比4.5以上を確認。既存を含め137テスト・lint・型チェックが成功。iPhone 17 Pro Maxシミュレーターで設定画面と5タブを確認。実機の連続選択・再起動後の保存復元は未確認です。
