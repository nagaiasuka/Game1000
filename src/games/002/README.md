# GAME #002 — BLOCK BREAK

1人用、縦画面の10ステージ制ブロック崩し。ルートは `/play/002`。

## 操作と進行

- STAGE SELECTで到達済みステージを選び、PLAY。初回は01のみ。クリア済みは✓。
- 0.45秒のREADY後、盤面のタップで発射。左右ドラッグは盤面全域で有効。パドル下の余白からも操作できます。
- 指の移動量でパドルを動かす相対操作。追従を補間し、端で反射角を変えられます。
- 初期3 LIFE。全ボールが落ちたときだけ1減り、残機があればタップ待ちへ戻ります。
- 右上Pause、バックグラウンド・Android通知シェード・画面離脱・250ms超の処理遅延で停止。RESUMEは時間を飛ばさず再開します。
- RESTART STAGEはそのステージ開始時のスコア・残機・最大コンボに戻ります。RETRY／ステージ選択開始はスコア0・3 LIFEの新規ランです。
- 全破壊対象を消すとCLEAR。破壊不能ブロックはクリア条件に含みません。NEXT STAGEで進み、10面クリアでALL STAGES CLEAR。
- ブロックは18×16の18列、隣同士を隙間なく配置。STAGE 01は66個、STAGE 09は追加分を含め256個の破壊対象。空白は壁の裏へ回り込む通路や囲いの入口として配置しています。
- STAGE 05〜10は最下段を壊すと上から列が追加されます。追加上限は順に4・5・6・6・8・10列。予告後に残ったブロックが1段下がり、壁は固定。ボールと重なる場合は出現を待ちます。すべての追加列を出し切って破壊するとCLEARです。
- HUDの「追加列」で残量を表示。追加待機はPause中も停止し、ステージ再開始時にリセットします。

- スコア・残機・コンボ・FEVER・BEST・追加列・アイテム残り時間・開発者表示はすべて盤面より上にまとめ、下側は盤面とドラッグ操作に使用します。
- 盤面は端末の安全領域内で、利用可能幅に対して左右各2.5%（合計5%）・下5%の可変余白を確保し、残り95%の横幅を使い、縦横同じ倍率で描画。パドルは下端から72論理単位上に配置。説明は盤面内に重ね、READY・発射・MISS・Pauseで盤面の高さを変えません。画面そのものの寸法変更時は一時停止して座標を調整します。余白率は `GameScreen.tsx` の `FIELD_MARGIN_PERCENT` で変更できます。小さい端末に合わせた幅の上限制限はありません。

## スコア・演出

- ブロック100点、耐久は最終破壊時に追加50点×（初期耐久−1）。
- 破壊から4.5秒以内の連続破壊でCOMBO。5コンボごとに倍率が上がり、最大5倍。
- 破壊でFEVERを蓄積。ステージごとの増加量はデータ定義。満タンで8秒間スコア2倍、軌跡・背景・パーティクルを強化。MISSでリセット。
- CLEAR BONUSはステージ番号×500点、LIFE BONUSは残機×250点。
- スコアポップアップ最大8、粒子最大48、ボール最大3、軌跡各6点、落下アイテム最大6。ブロック層はmemo化し、ヒット時以外の再描画を避けます。
- Hapticsはフレーム内のイベントをまとめ、通常90ms／強いイベント60ms以上の間隔。SE・BGMは共通Audio基盤へ接続。`drainEvents()`を振動・効果音で共有します。

## アイテム

破壊時9%で、3種類から等確率で落下。ブロック数増加に合わせて頻度を調整しています。乱数はエンジンへ注入可能です。

| 表示 | 効果 |
| --- | --- |
| ×3 | 最大3ボールへ追加。全滅またはステージ移行まで |
| W | パドル幅90→126、12秒 |
| P | 8秒間、破壊可能ブロックを貫通。耐久は1接触につき1ダメージ。鋼は反射 |

アイテム再取得時は時間を更新。MISS／ステージ移行で解除。Pause中は効果時間も停止します。

## 内部構成

- `stages.ts`: FIRST HIT / WALL / PYRAMID / TUNNEL / NEON RUSH / FORTRESS / SPLIT / CHAOS / DOPAMINE / FINAL BREAK。18列の文字列で配置、耐久、速度、FEVER増加量、追加列の柄・上限を調整。
- `logic/physics.ts`: 掃引衝突判定、パドル反射。論理幅360・高さは端末の盤面サイズに追従（既定600）、速度上限400。
- `logic/engine.ts`: 120Hz固定ステップ。描画FPSから独立した位置・衝突・アイテム・時間・状態遷移。
- `components/Field.tsx`: 画面サイズに合わせた描画とPanResponder。複数指／操作中断／フェーズ変更で入力を破棄。
- `hooks/useBlockBreak.ts`: RAF・AppState・保存・Haptics。
- `storage/records.ts`: 直列化したread/merge/write。BEST・到達面・クリア済みを後退させません。

## 保存キー

HOME右上のキラキラを5秒長押しし、パスワード `pass` を入力すると開発者モードになります。全10ステージを選択でき、DEV MODEを表示します。テストプレイのBEST・解放面・クリア状況は保存しません。HOMEの同じアイコンから解除でき、アプリの再起動でもOFFになります。

- `@game1000/game002/best-score/v1`
- `@game1000/game002/stages/v1`（最高到達面とクリア済み面）

得点発生後最大約2秒ごと、およびMISS・CLEAR・Pause・再開始・画面離脱で保存。読込・保存エラー時もプレイを続け、画面に通知して再試行します。GAME #001の保存処理・キーには触れていません。
