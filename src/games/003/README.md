# GAME #003 — NEON STACK

スマホ1台を交互に操作する、2人専用の「かぶせる三目並べ」。ルートは `/play/003`。CPU・通信対戦・対戦結果の永続保存は初期版に含めません。音は共通Audio基盤へ接続しています。

## ルールと操作

- プレイヤー1はシアンの1本ツノ、プレイヤー2はピンクの2本ツノのモンスター。ツノの数・色で区別します。開始前に12文字まで名前を入力できます。空欄はプレイヤー1・2を使用し、再戦中も名前を保持します（画面を離れるとリセット）。
- 各自が小・中・大を2個ずつ、合計6個持ちます。`logic/rules.ts` の `PIECES_PER_SIZE` で変更できます。
- 下の手持ちで大きさを選び、置きたいマスをタップ。置けるマスは枠と「置ける」で案内します。配置後は選択を解除し、次の人が選び直します。
- 空マスにはどのサイズでも置けます。自分・相手どちらの駒にも、より大きい駒ならかぶせられます。同じサイズや小さいサイズは置けません。置いた駒の移動はありません。
- 各マスは `readonly Piece[]`、下から上への順序です。`Piece` は `id / player / size`。覆われた駒も削除せず、最上部だけで勝利判定します。
- 縦3・横3・斜め2の全8本を判定。3つそろうと勝利ラインが光り、駒・粒子の演出と結果を表示します。
- 次の人に合法手がなければその番を自動で飛ばし、理由を日本語で表示します。両方とも置けず勝者もいない場合は引き分けです。配置のみのため最大12手で終了します。
- 「1手戻す」は1回押すごとに直前の配置を取り消し、覆われた駒・手持ち・手番・勝利数・対戦数をまとめて復元します。決着後も利用可能。新しい対戦では履歴をクリアします。
- 先攻は開始・再対戦・やり直しごとにランダム。乱数はエンジン側で注入可能です。
- 結果の「もう一度対戦する」を主ボタンにし、勝利数を画面のセッション内で保持します。やり直し時も勝利数は残し、ホームへ離れるとリセットします。
- 最初の画面に短い3項目の説明を表示。ヘッダーの「？ 遊び方」で5項目の説明をいつでも確認できます。リアルタイム進行がないため一時停止は不要です。
- ホームへ戻る・途中のやり直しには確認ダイアログがあります。バックグラウンドでは自動進行せず、復帰後も同じ盤面です。

## UI・演出

- 対戦・結果画面にはScrollViewを使わず、安全領域内の固定HUDと操作欄の間を実測して正方形の盤面を最大化します。対戦・結果で操作欄の高さをそろえ、盤面サイズを維持。HUDは文字拡大を最大1.2倍に制限し、長い名前は省略表示します。手持ちと操作ボタンは44pt以上を確保。名前入力・遊び方はスクロール可能です。
- 駒はサイズ差のあるツノ付きモンスター。配置180ms、相手へのかぶせ・勝利280msの落下演出と粒子。勝利ライン・文字・ツノの形に色だけの判断を要求しません。
- iOSのHaptics：通常Light、相手へのかぶせMedium、勝利Success、不正配置Warning。Androidでは対応するシステムHaptics。連続振動は90ms以上あけ、利用不可の環境でもゲームを続行します。
- `logic/session.ts` の `Feedback` は配置・かぶせ・勝利・引き分け・不正配置を分離し、SEにも接続しています。外部音源は取得していません。

## ファイル

- `logic/types.ts / rules.ts / engine.ts`：UI非依存の型・合法手・勝利判定・不変更新。
- `logic/session.ts`：選択・二重タップ防止・再対戦・勝利数・取り消し履歴。Reactの再実行でも二重加点しません。
- `hooks/useNeonStack.ts`：セッションとHapticsの接続。
- `components/Board.tsx`：3×3盤面、駒、重なり、アニメーション、勝利ライン。
- `GameScreen.tsx / presentation.ts`：日本語UI、開始・結果・確認、表示用文言。
- `src/data/catalog.ts / ui-text.ts`：公開登録と共通の遊び方。
- `src/components/game-artwork.tsx`：ネイティブ図形によるプレビュー画像。ホーム・一覧に表示。
