# GAME #004 — NEON PATH

1台で2人が交互に遊ぶ、9×9の経路対戦。人型の1は下から上、2は上から下へ。各10枚の壁を持ち、1手で移動か壁設置を選ぶ。名前は任意、初戦は1が先攻、再戦では先攻を交代する。名前・対戦状態はこの画面内だけで保持する。

## ロジック

`logic/engine.ts` はReact/Expo非依存。通常の上下左右移動、隣接相手の飛び越え、後ろが壁または盤外のときの側方移動を判定。壁は8×8の交点を起点に2辺を遮断し、部分重複・交差は禁止。壁の仮適用後、双方の現在位置からゴールへの経路をBFSで確認する。相手の駒は恒久障害物として扱わない。BFS距離は駒による飛び越えを含まない経路の目安。

`logic/session.ts` は1つ前の盤面だけを保持する。Undoで移動・壁・枚数・手番を復元し、その直後の再Undoは禁止。勝利後はUndo不可。単調増加revisionで前の画面から届いた連打を拒否。不正な配置では盤面・手番・残り壁を変更しない。

## 表示と操作

対戦中はScrollViewを使用しない。SafeArea内に固定HUD・86ptの操作欄を確保し、残った実測領域に正方形の盤面を最大サイズで配置する。左右余白は合計5%。勝敗や壁モードによって盤面サイズを変更しない。高さが足りない端末では手番をプレイヤーカード内にまとめる。名前入力と長い遊び方だけスクロール可能。

移動は光るマスを直接タップ。手元の壁はタップで縦横を回転、盤面へドラッグすると交点にスナップして配置予定を表示。盤面内の合法位置で指を離すと壁を確定して交代。盤外・不正配置・OSのジェスチャー中断では確定せず手番を保持する。「進む」「壁を置く」「置く」「やめる」の操作ボタンは撤去し、Undoは残す。壁のドラッグは実機のタッチ操作が必要。

移動可能マス、人型の駒のヘルメット形状と番号、ゴール方向、残り壁数、手番を常時表示。メインカラーは共通テーマに追従し、プレイヤー色は固定。勝利時はゴール発光・駒からの光・中央の勝者表示、結果欄に総手数と壁の使用数、HUDに残り壁数を表示する。

## 音

共通Audio Managerに004シーンを登録。開始前はHOME BGM、開始後は専用「QUIET CIRCUIT」、決着後はBGM停止。移動・ジャンプ・壁・ゴールはそれぞれ専用SE、選択・回転・Undoは共通UI音。警告・ゴール・壁の確定では同じイベントからHapticsも発火する。BGM/SE設定は共通のものを使用する。

## 検証

`tests/neon-path.test.ts`：盤外・壁越え・ジャンプ4方向・側方移動・壁の重複と交差・両者の完全封鎖禁止・枚数消費・両者の勝利・Undo制限・連打・警告・SE登録を確認。50試合の乱数シミュレーションでは、別実装の辺グラフで両者の経路が残ることも確認する。

実機の操作感・音量・振動の確認は別途必要。CPU・オンライン対戦・対戦の永続保存は対象外。

iPhone 17 Pro MaxのExpo Goで表示を確認。320×568ptの制約を一時的に与えた小型画面相当でも、初版の盤面・HUD・操作欄が収まることを確認した（別機種そのものの実機検証ではない）。検証用の初期状態・固定サイズは削除済み。直接操作への変更後、既存を含む157テスト・lint・型チェックが成功。新しいドラッグ操作の実機確認は未実施。
