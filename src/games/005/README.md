# GAME #005 — NEON SLING

1台のスマートフォンを縦に机へ置き、上下から2人が同時に遊ぶスリング対戦。開始時は各5個、パックは白い共通駒。自分側の止まったパックを手前へ引いて離し、中央ゲートへ送る。自分側を先に0個にすると勝利。所有権はなく、完全に届いて止まったパックは送り返せる。CPU・オンライン・任意の練習画面は初版に含めない。

## 対称なレイアウト

SafeArea内を横方向に分割。右HUDは幅の13%（44〜60pt）で、戻る・設定・残数・停止・遊び方を置く。フィールドに片方だけのボタンやヘッダーを設けない。フィールドを実測し、HUDを除いた幅を物理座標360に対応させる。上下は同じ高さ、半径、初期配置の鏡像、摩擦、引っ張り上限、速度。プレイヤー2向け文字は180度回転。対戦画面はスクロールなし。開始・勝利・設定でフィールドサイズを変えない。

## 同時操作

`Field.tsx` はフィールド全体でネイティブのchangedTouchesを受け、page座標からフィールド原点を引いて変換する。エンジンは文字列/数値のopaqueなtouch IDをパックとプレイヤーに結び付ける。1人1個、計2個まで。片方の指の移動・解除はもう片方に影響しない。3本目・移動中・ゲート通過中・盤外の開始を拒否。小画面の選択判定は直径44pt以上の範囲から最寄りの対象を選ぶ。

パックは照準の起点に保持し、引いた位置に輪、間にゴム線、反対側に発射ガイドを描く。強さを色・長さ・線幅で表示。引き量100で最大速度1100、10未満の引き、逆方向への引き、touch cancelでは発射しない。OSやHUDへのレスポンダー移譲は両手を解除。設定・ヘルプ・終了確認は物理停止し、閉じたら再開。アプリ離脱とAndroidのblurは停止し、復帰後は明示的に再開する。

## 物理

`logic/engine.ts` はExpo/React非依存。120Hz固定刻み、描画は約60Hz。長いフレームは0.1秒までで復帰後の追いつき演算を制限。円同士の等質量反射、保持中は静止障害物、円と中央の2つの長方形の衝突、四辺、指数摩擦、速度制限を計算する。中央角は最近点の法線で反射。粒子は12組まで、通常衝突イベントは65ms間隔に制限。

パック全体が中央壁の厚みと半径を抜けた時点で陣地を更新。通過中は元の陣地の残数に含め、全パックを同じステップだけ進めてから判定する。ゲート内で極低速になった場合だけ、移動方向への小さな速度で抜け切るよう補助し、掴めないまま永久に止まる状態を防ぐ。通過中のパックが1つもなく、片方が0個になれば勝利。全速度と保持をリセットし、セッション勝利数を1回だけ増やす。

## オーディオと演出

共通Audio Managerの005シーン。開始前はHOME BGM、対戦開始から専用曲「CROSSFIRE」。142 BPM・16小節、掛け合う短いスタブとブレイクビートで対戦を表現し、BLOCK BREAKとは別の譜面。自作の選択・発射・衝突・通過・勝利・カウントSE。全設定は共通BGM/SE設定に従う。通過・発射・勝利はHapticsを併用。残り1個で外周が脈動、通過時にゲート発光、勝利側にネオン波と粒子を描画する。

## 検証

初期配置の対称性、カウントダウン、2指の独立操作、同一側の多指禁止、キャンセル、引き量上限、ゲートと角の反射、連鎖衝突、保持中の衝突、摩擦、通過中の残数、同時反対通過、勝利、再戦、Pause、画面変更、描画レート非依存、鏡像の軌道、効果音登録を自動テスト。3種類の高さで各5000ステップの高速ランダム入力について位置・速度・残数・エフェクト上限を確認。

iPhone 17 Pro MaxのExpo Goで対戦画面の表示を確認。2人が実際に同時に指で引く操作、Android実機、実機のFPS・音量・振動は未検証。自動テストの同時操作検証はエンジンに対する入力であり、ネイティブイベント経路の実機保証ではない。

既存を含む180テスト・lint・型チェックが成功。320×568ptの領域に一時的に制限した小型画面相当の表示も試したが、Expo Goの初回案内が下部に重なったため、その下部の目視確認は未完了。別機種そのものの実機試験も未実施。検証用の固定サイズ・自動開始は撤去済み。

## 爽快感の調整

中央ゲート幅は66（フィールド幅360、パック直径30）。初版94より約30%狭くし、左右の壁を各147にして中央を狙う配置にした。物理判定と描画は同じ定数を参照する。発射時の波紋、6段の残光、衝突の放射状火花、ゲート通過時の16本の火花と広がる光、勝利時の3重波紋と28粒の演出を追加。プレイ中のエフェクトは最大12組の上限を維持し、停止中は進行しない。演出はタッチを受け取らず、フィールドを揺らしたりレイアウトを変えたりしない。
