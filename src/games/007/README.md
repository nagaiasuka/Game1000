# GAME #007 — NEON FISH

2〜4人で1台を順番に使う釣り大会。タップで選び、針がかかったら上へ28pt以上スワイプするか「釣り上げる」を押す。胴体のブロック数が得点で、全員の合計を競う。同点は同順位・同点優勝。

- 2・4人：2〜9の8匹。2人は各4回、4人は各2回。
- 3人：2, 3, 4, 5, 5, 6, 7, 8, 9の9匹。各3回。
- Fisher–Yatesで長さを割り当てる。色・外観・位置・泳ぐ速度は魚IDだけで決まり、長さから独立。釣る前の魚には番号・得点を表示せず、アクセシビリティも位置だけを案内する。長さは伸長中の開示ブロックだけで表す。
- `logic/engine.ts` はExpoに依存しない状態機械。選択→針→引き上げ→1ブロックずつ開示→得点確定→交代。演出中の入力・二重加点を拒否。再戦時は名前を保持し、先手をローテーション。
- `useNeonFish.ts` は一度に1つのタイマーを持ち、停止時には次の開示までの残り時間を保持。各開示イベントがカウンター・音程の異なるSEを同時に更新する。最終長を描画コンポーネントへ演出用パラメーターとして渡さない。
- `components/Pond.tsx` は共通の自作魚パーツを使用。泳ぎ、釣り針、水しぶき、蛇腹のスプリング、頭の上昇、残像、大物のリング。最大9ブロックでは最後の1ブロック前の間を長めにする。激しい点滅なし。
- 共通テーマ・安全領域・名前入力・遊び方・音声設定を利用。遊び方、手動停止、OS中断からは明示的に再開。終了・やり直しは確認画面を出し、結果からの再戦には確認なし。
- 対戦画面の盤面は残り領域へ縮小し、固定HUDと操作ボタンを確保。開始・結果・停止メニューはスクロール可能。

音源は `scripts/generate-fish-audio.py` の自作合成。専用BGMは132 BPM、64拍ループ。9段階の上昇SE、針、水しぶき、4段階の釣果、逆転、勝利を共通AudioManagerのシーンに登録。伸長中のBGMは設定音量の35%、結果は0%にフェードして勝利SEを優先。別シーンの音量には影響しない。

検証：`npm run lint`、`npm run typecheck`、`npm test`。ルール、全人数の公平性、得点保存則、同順位、逆転、操作ロック、演出時間、カタログ・ランダム選択・音声設定を検証。端末の音声遅延・触覚・着信中断・実機FPSは別途実機確認が必要。

ブラウザ操作検証：390×844の2人、320×568の3人、430×932の4人で全試合を完走。320×568の4人でも実タッチスワイプ・順位とラウンド・先手交代・リスタートを確認。停止中のタイマー保持、遊び方からの明示的再開、終了確認も確認し、実行エラー0件。Web専用の一時設定は検証後に削除済みで、製品の対象プラットフォーム・依存関係は変更していません。
