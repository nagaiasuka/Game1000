# GAME #008 NEON CASCADE

1人用の縦画面ゲーム。盤面を触って狙い、指を離して発射します。下の「左へ」「右へ」「発射」でも操作可能です。重力・反射・増殖ゲートを使い、制限ショット内で全目標を壊します。コアはフィーバー中だけ破壊できます。

## 構成

- `logic/engine.ts`：Expoに依存しない純TypeScript。1/120秒固定刻み、最大64球の固定プール、連続衝突判定、空間グリッド、スコア・連鎖・フィーバー・ショット終了。
- `logic/physics.ts`：円対矩形（角を含む）・円対円のsweep、空間検索。
- `stages.ts`：異なる10コースとエンドレスの決定的な波生成。
- `useNeonCascade.ts`：エンジンとReactの橋渡し。球・ゲート座標はReanimatedへ毎フレーム渡し、HUDは原則100msごと。AppState/focusで停止し、明示操作で再開。
- `components/Field.tsx`：縦横比を保つ固定論理盤面360×600。64球ノードを再利用。エフェクト最大18個、控えめ設定あり。
- `GameScreen.tsx`：ステージ選択・プレイ・結果・一時停止。共通テーマ、日本語文言、SafeArea、共通サウンド設定を利用。
- `audio.ts`：衝突をまとめ、通常音は1回最大2件。優先音・発音間隔を制御し、共有AudioManagerの最大4同時音制限を併用。
- `storage/`：既存AsyncStorage利用。独立キー `@game1000/game008/records/v1`、破損値の復旧、直列保存、最高値のマージ。

## ルール

発射後は全球が画面外へ戻るか16秒経過するとショット終了。0.18秒の集計後、全目標破壊ならクリア、残弾0なら終了です。球同士は衝突しません。同じ系統の球は同じゲートを1回だけ通過できます。子球は次の固定ステップから処理します。

命中10点。破壊は100点×連鎖段階（最大5）×フィーバー倍率2。連鎖猶予2.5秒、命中0.2・破壊2でゲージを加算し、10で8秒間のフィーバー。未使用ショットは1回250点。星はクリアしたショット数で決まり、最高点とは別に最高星を保存します。

二重発射はphaseで拒否。破壊前にHPを0にするため爆弾の再帰連鎖でも二重加点しません。長いフレーム停止（250ms超）は無理に追い付かず一時停止します。

## 10コース

全ステージの条件は全目標破壊（9はフィーバー中のコア破壊を含む）。星1は制限内クリア、星2・3は下表の使用ショット数以内です。難易度は設計上の目安です。

| # / コース       | 構造・目標                   | 発射上限 | 星3 / 星2 | 攻略体験・難易度                       |
| ---------------- | ---------------------------- | -------- | --------- | -------------------------------------- |
| 1 はじめの連鎖   | 通常4個、幅広×2              | 4        | 2 / 3     | ゲートと狙いの基本・入門               |
| 2 壁の向こう     | 左右6個、中央障害、左右×3    | 5        | 3 / 4     | 中央を避けて側壁反射・初級             |
| 3 分かれ道       | 高低差のある左右6個、仕切り  | 4        | 2 / 3     | 広い×2と狭い×3の選択・中級             |
| 4 集中突破       | HP3の装甲4個、×4、側面壁     | 5        | 3 / 4     | 同一箇所へ球を集中・中級               |
| 5 爆発の導線     | 通常12個＋爆弾3個、×3        | 4        | 2 / 3     | 爆弾を起点に面を崩す・中級             |
| 6 スイッチ回廊   | 鍵1個＋奥4個、扉、×2→×4      | 5        | 3 / 4     | 通路を開いて上段へ・中上級             |
| 7 動くチャンス   | 高低差6個、移動×8、段差壁    | 5        | 3 / 4     | 動くゲートを待って発射・上級           |
| 8 バンパーループ | 散在8個、丸バンパー2個、×8   | 5        | 3 / 4     | 曲面反射で奥へ送る・上級               |
| 9 フィーバーコア | 通常8＋爆弾2＋HP3コア、×4→×4 | 5        | 3 / 4     | 周囲を崩してフィーバー中にコアへ・上級 |
| 10 大瀑布        | 装甲7＋通常7＋爆弾3、×2を6段 | 6        | 4 / 5     | 最大64球と爆風の総合戦・最上級         |

物理調整後の正式な配置は `stages.ts` が正です。攻略可能性は `tests/cascade-solutions.json` の合法な角度・待機・発射だけで検証します。HPやスコアを注入してクリアさせません。10コース×30/60/120fpsで同じ得点・星3を確認します。角度近傍試験は最短手順の頑健性の参考で、全入力でのクリア保証ではありません。

エンドレスは10種の検証済みコースを循環し、10波ごとにHPを1追加（追加上限3）。ショット数は基本コース＋1、最低4。次の波へ得点を引き継ぎ、終了ごとに最高点と到達波を保存します。再挑戦は第1波からです。後半の全波の自動クリア証明は行っていません。

## サウンド

外部音源なしで専用の通常・フィーバーBGM各16小節を作曲し、14個の専用SEを制作しました。詳細は [音源資料](../../../assets/audio/README.md) と [検証・実機確認票](../../../docs/neon-cascade-validation.md)。音程は6種類の書き出し済み命中音を連鎖に合わせて選択し、ネイティブpitch APIへの依存を避けています。

## 開発・検証

Node.js 24系。依存追加はありません。

```sh
npm test
npm run lint
npm run typecheck
node --experimental-strip-types scripts/cascade-solve.ts
node --experimental-strip-types scripts/cascade-replay-check.ts /tmp/cascade-nearby.json
node --expose-gc --experimental-strip-types scripts/cascade-benchmark.ts /tmp/cascade-benchmark.json
python3 scripts/cascade-audio-check.py > /tmp/cascade-audio-check.json
python3 scripts/generate-cascade-audio.py
```

solveは全10コース成功時に攻略fixtureを更新します。ベンチはCPUのみ。60fps・実機の音質・遅延・発熱の確認とは区別してください。
